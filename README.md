# Тест_ОВ

Мобильная Android-версия приложения для тестирования по нормативным документам ОВиК.

## Первая версия

В проект встроен один банк вопросов: **СП 7.13130.2013 «Отопление, вентиляция и кондиционирование. Требования пожарной безопасности»**.

Реализовано:
- режим **«Контрольные вопросы»**;
- режим **«Обучение»**;
- вопросы типов **текстовый / один ответ / несколько ответов**;
- случайная выборка 25 вопросов для контрольного режима;
- таймер 15 минут;
- переход назад и вперёд;
- правильный ответ и источник в режиме обучения;
- итоговый результат;
- встроенный шрифт для русского текста;
- иконка приложения.

## Как получить APK через GitHub

После загрузки проекта в ветку `main` откройте вкладку **Actions** → **Build Android APK**. Сборка запускается автоматически при изменении кода. Её также можно запустить вручную кнопкой **Run workflow**.

После успешной сборки откройте завершённый запуск. Внизу страницы в разделе **Artifacts** появится архив **Test_OV-apk**. Внутри него находится APK для установки на Android.

## Основные файлы

- `main.py` — логика приложения.
- `testov.kv` — мобильный интерфейс Kivy.
- `data/questions.json` — встроенный банк вопросов.
- `assets/icon.png` — иконка приложения.
- `fonts/Arial.ttf` — ресурс шрифта приложения.
- `buildozer.spec` — параметры Android-сборки.
- `.github/workflows/build-apk.yml` — автоматическая сборка APK на GitHub Actions.
